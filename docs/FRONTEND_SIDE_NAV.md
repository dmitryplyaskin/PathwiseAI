# Frontend: боковая панель и оболочка приложения

## Структура

- `web/src/widgets/side-nav/navigation.ts`: маршруты, иконки, правила активного состояния, ширины и ключ localStorage.
- `web/src/widgets/side-nav/ui/SideNav.tsx`: адаптивный MUI Drawer, ссылки и блок аккаунта.
- `web/src/app/ui/Layout.tsx`: мобильное открытие, сохранение компактного режима, breadcrumbs и основной контент.
- `web/src/shared/config/theme.ts`: общая синяя палитра, нейтральные поверхности, типографика и фокус.

## Навигация

Единый блок «Обучение»: Главная, Мои курсы, Повторение, История тестов.
Профиль доступен по строке аккаунта внизу, рядом находится выход.
Для вложенных страниц курсов активным остаётся пункт «Мои курсы».
Ссылки используют React Router Link и поддерживают открытие в новой вкладке.

Desktop (`md+`): постоянная панель 256 px или компактная 76 px. В компактном режиме доступны подписи через tooltip. Переключатель находится внизу, отдельно от логотипа.
Mobile: временная панель с явной кнопкой закрытия. Открывается кнопкой рядом с breadcrumbs, закрывается по ссылке, Escape или backdrop. MUI управляет фокусом и блокировкой фона. При переходе на desktop мобильное состояние сбрасывается.

Ключ `pathwise.sidebar.collapsed.v1` сохранён для совместимости: `1` — компактная, `0` — полная. Недоступный localStorage не мешает работе.

## Доступность

- `aria-current` у активных ссылок, `aria-expanded` у переключателей.
- Подписи у кнопок с иконками, видимый клавиатурный фокус.
- Ссылка «Перейти к содержимому» ведёт к основному `main`.
- При малой высоте панель прокручивается; учтён нижний safe area.
- Общая тема отключает анимации при prefers-reduced-motion.

## Как добавить пункт

Добавьте запись в `NAVIGATION`. Для вложенных маршрутов задайте `nested: true`; остальные сопоставляются точно. Панель использует единую конфигурацию маршрутов.

## Связанные изменения интерфейса

Главная: учебный заголовок, кнопка создания урока, три показателя из существующих API-данных. Во время загрузки или ошибки показатель отображает тире. Плавающая кнопка создания заменена действием в заголовке; формы создания сохранены.

Каталог: единый заголовок, поиск с подписью, переносимые фильтры. Убран фиксированный рейтинг 4.7, пустой каталог больше не даёт NaN среднего прогресса. Режим списка использует одну колонку. Сброс фильтров доступен и при фильтрации только по статусу; пустое состояние не появляется при загрузке или ошибке.

## Проверки редизайна

- Production build и TypeScript.
- ESLint изменённых файлов.
- Браузер: вход test, главная и каталог, компактная панель и сохранение после reload.
- Мобильные размеры 390 и 320 px: панель, переход в каталог, Escape и возврат фокуса.
- Главная и каталог на 320 px без горизонтального переполнения страницы.

Полный аудит остальных страниц и проверка отдельным экранным диктором не проводились.

Глобальный верхний бар удалён: на desktop контент начинается сразу, на мобильных кнопка меню находится в строке breadcrumbs без отдельной шапки.
